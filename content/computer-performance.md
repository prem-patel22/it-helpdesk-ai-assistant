# Computer Performance Troubleshooting

## Computer is running slow

### Quick fixes (try in order)

**1. Restart your computer**
- Fixes 90% of performance issues
- Save work → Restart

**2. Close unused programs**
- Press Ctrl + Shift + Esc
- Look for programs using high CPU/Memory
- Right-click → End Task

**3. Clear temporary files**
- Press Windows + R
- Type: %temp%
- Delete all files (skip if in use)

**4. Check disk space**
- Open File Explorer
- Check C: drive free space
- If less than 10GB free, delete old files

**5. Check for Windows updates**
- Settings → Windows Update
- Install pending updates
- Restart computer

## Serious issues (contact IT)
- Computer takes more than 5 minutes to start
- Blue screen errors appear
- Programs crash every hour
- Fan is constantly loud
